### 🚀 Featured projects

**[MediSync](https://github.com/Chamod-Tharusha-Alwis/MediSync)** · [Live](https://medisync.chamodtharusha.com.lk/) · [Case study](https://www.chamodtharusha.com.lk/projects/medisync.html)<br>
AI-driven healthcare platform for Sri Lanka, built solo across three services: React 19, Node.js/Express 5 and a Python Flask ML engine.
- Outbreak forecasting with Prophet, ARIMA and z-score anomaly detection, shown on a public district risk map (Leaflet, GeoJSON).
- AES-256 field-level encryption with blind indexes, HashiCorp Vault, OTP checks on patient records and audit logs.
- Drug-interaction checks covering 191k+ pairs; initial JS bundle cut from 465 KB to 145 KB with code-splitting.

**[Ayu Arana Care](https://github.com/Chamod-Tharusha-Alwis/Ayu-Arana-Care)** · [Live](https://ayu-arana-care.chamodtharusha.com.lk/) · [Case study](https://www.chamodtharusha.com.lk/projects/ayu-arana-care.html)<br>
Management system for an elders' care home (team project, I was the backend developer): REST API with role-based access and bcrypt, resident medical records, memberships and payments. MERN + Tailwind CSS.

**[Ceylon Traveler](https://github.com/Chamod-Tharusha-Alwis/Ceylon-Traveler)** · [Live](https://ceylon-traveler.chamodtharusha.com.lk/) · [Case study](https://www.chamodtharusha.com.lk/projects/ceylon-traveler.html)<br>
Travel and accommodation booking platform for Sri Lanka (solo): hotel, taxi and guide booking with availability checks and JWT authentication. MERN.
